# 🚗 Hanuman Travels - Self-Drive Car Rentals

A professional, responsive web application built for **Hanuman Travels**, a car rental service based in **Thurputhallu, India**. This project allows local customers to browse available vehicles, view rental terms, and book directly via WhatsApp.

### 🌐 Live Demo
Check out the live site here: [Hanuman Travels Live](https://mohan-9121.github.io/hanuman-travels/)

---

## ✨ Features
* **Dynamic Fleet Display:** Showcases premium cars like the Maruti Suzuki Grand Vitara and Fronx with pricing.
* **Smart Booking System:** Integrated JavaScript validation to prevent past-date bookings.
* **WhatsApp API Integration:** Customers can send booking details directly to the business owners.
* **Responsive Design:** Optimized for mobile users in the Thurputhallu and Narsapuram regions.
* **Google Maps Integration:** Precise location tracking near Satya Sairam Theater.
* **Security Deposit:** Customers must submit their own bike while taking the car.
* **Advance Payment:** 50% non-refundable advance required to confirm booking.

---

## 🚀 Technical Skills Used
* **HTML5:** Semantic structure for the rental portal.
* **CSS3:** Custom UI/UX design with a premium "Dark Luxury" theme and mobile-first responsiveness.
