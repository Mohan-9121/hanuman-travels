# 🚗 Hanuman Travels - Self-Drive Car Rental Website

This is a **Full-Stack Web Application** built using **Django** and **MySQL** for a car rental business based in Thurputhallu.

## 🌟 Features
* **Dynamic Car Listing:** View available cars like Suzuki Fronx and Grand Vitara.
* **Availability Status:** Real-time checking if a car is "Available" or "Already Booked."
* **Database Management:** Uses MySQL to store car details and booking status.
* **Responsive Design:** Mobile-friendly UI built with HTML5 and CSS3.

## 🛠️ Tech Stack
* **Backend:** Python, Django 5.0
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** MySQL / SQLite
* **Version Control:** Git & GitHub

## 🚀 How to Run Locally
1. Clone the repository.
2. Install requirements: `pip install -r requirements.txt`
3. Run migrations: `python manage.py migrate`
4. Start the server: `python manage.py runserver`
